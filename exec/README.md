## 3분 요약

세 덩어리가 EC2 한 대 위에서 Docker Compose 로 돈다. 앞단은 호스트 Nginx 하나가 받는다.

```
                          https://j15a403.p.ssafy.io
                                    │
                          ┌─────────▼─────────┐
                          │   Nginx (호스트)   │
                          └───┬───────────┬───┘
            정적 파일 (root)  │           │  /api → 127.0.0.1:8080
   /var/www/j15a403/frontend  │           │
                              │      ┌────▼─────────────────────┐
                              │      │ ai-block-clock-backend   │  Spring Boot 4.1 / Java 25
                              │      │ :8080                    │
                              │      └────┬──────────┬──────────┘
                              │           │          │
                              │   ┌───────▼──┐  ┌────▼──────────────────────┐
                              │   │  mysql   │  │ ai-block-clock-ai-runtime │ :8000
                              │   │  8.4     │  │ ai-block-clock-recommend  │ :8100
                              │   └──────────┘  └────┬──────────────────────┘
                              │                      │
                              │                      └─→ SSAFY GMS (Gemini 2.5 Pro)
                              └─→ 브라우저 MetaMask ──→ SSAFY 체인 (31221)
```

- 컨테이너 4개(`backend` · `mysql` · `ai-runtime` · `recommend`)가 **하나의 Docker 네트워크**
  `ai-block-clock_ai-block-clock-network` 를 공유하고, 서로를 컨테이너 이름으로 부른다.
- 프론트는 컨테이너가 아니다. Vite 빌드 산출물(`dist/`)을 Nginx 가 직접 서빙한다.
- 배포는 GitLab Runner(shell executor)를 **배포 서버에 직접 등록**해서 한다. SSH 키가 필요 없다.

## 가장 자주 막히는 네 가지

1. **추천 서비스 모델 가중치(423MB)는 이미지에 없다.** `/opt/abc/models` 에 풀어 두지 않으면
   컨테이너가 기동 단계에서 죽는다 → [01-포팅매뉴얼 § 4.3](01-포팅매뉴얼.md#43-추천-서비스-가중치--인덱스-필수)
2. **HTTPS 가 아니면 로그인이 안 된다.** 지갑 서명 메시지의 도메인과 세션 쿠키 `Secure` 가
   실제 접속 주소와 같아야 한다 → [01-포팅매뉴얼 § 4.4](01-포팅매뉴얼.md#44-지갑-로그인--https)
3. **운영 DB 이름과 계정이 compose 기본값과 다르다** (`ai-block-clock` / `admin`).
   GitLab 변수를 같이 옮기지 않으면 빈 DB 가 새로 만들어진다 → [db/README](db/README.md#db-정보)
4. **개인키는 저장소에 없다.** 없으면 출금 지급 · 원본 증명이 대기 상태로만 쌓인다.
   다만 **현재 운영은 둘 다 켜져 있어 실제로 체인에 나간다**
   → [02-외부서비스 § 6](02-외부서비스.md#6-지갑--개인키-정리)
