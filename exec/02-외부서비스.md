# 2. 외부 서비스

프로젝트가 밖에 의존하는 것과, 각각을 새로 준비하려면 무엇을 해야 하는지 적는다.

## 한눈에

| 서비스 | 무엇에 쓰나 | 키 · 계정 필요 | 없으면 |
| --- | --- | --- | --- |
| SSAFY GMS | LLM (Gemini 2.5 Pro) 호출 | **팀 API 키** | 실행이 전부 실패. `ai:deploy` 도 실패 |
| SSAFY 블록체인 | abcToken 충전 · 출금 지급 | RPC 는 공개 / 지급은 **개인키** | 충전 확인 불가, 출금이 `APPROVED` 에서 대기 |
| SSAFY 토큰증권(STO) API | abcToken 발행, 에이전트 등기부 기록 | **등기부 지갑 개인키** | 원본 증명이 `PENDING` 으로 적재만 됨 |
| MetaMask | 로그인 서명, 충전 송금 | 사용자 각자 설치 | 로그인 불가 |
| GitLab (lab.ssafy.com) | 저장소 · CI/CD · Runner | 프로젝트 Runner 토큰 | 자동 배포 불가 (수동 배포는 가능) |
| Docker Hub / ghcr.io | 베이스 이미지 pull | 익명 | 빌드 불가 |
| Hugging Face | 추천 모델 아키텍처 | 불필요 (오프라인) | – |

**소셜 인증(Google · Kakao 등)은 쓰지 않는다.** 로그인은 지갑 서명으로 대신한다.
**포톤 클라우드 · 코드 컴파일 서비스도 쓰지 않는다.**

## 1. SSAFY GMS — LLM

노드가 AI 를 부를 때 쓰는 유일한 모델 공급자다. Google Generative Language API 를
SSAFY 가 프록시한다.

| 항목 | 값 |
| --- | --- |
| 엔드포인트 | `https://gms.ssafy.io/gmsapi/generativelanguage.googleapis.com` |
| 모델 | `gemini-2.5-pro` |
| SDK | `google-genai` (Python) |
| 키 변수 | `LLM_API_KEY` (GitLab CI/CD Variables, **Masked**) |
| 엔드포인트 변수 | `LLM_BASE_URL` — 비우면 Google 로 직접 붙는다 |
| 모델 변수 | `LLM_MODEL` |

**가입 · 발급**

1. SSAFY GMS 포털에서 팀 단위로 API 키를 발급받는다.
2. GitLab **Settings > CI/CD > Variables** 에 `LLM_API_KEY` 를 **Masked** 로 등록한다.
3. 로컬에서 쓰려면 `ai/spike/linear-mvp/.env` 에 넣는다 (`.env.example` 참고). 커밋 금지.

**사용량 주의**

- CI 의 `ai:test` 는 `--mock` 으로 돌아 **LLM 을 호출하지 않는다.** 무료 등급 상한을
  파이프라인이 소모하지 않게 한 것이다.
- 노드 하나당 실측 원가 0.005 ~ 0.009 달러(09-26). 플랫폼은 여기에 1.5배 마진을 붙여
  `NODE_BASE_COST_DEFAULT=0.0135` ABC 로 쓴다.
- 판매자의 테스트 실행은 무료라서 모델 요금을 플랫폼이 낸다. 노드마다 하루 5회로 막아 둔다
  (`NODE_TEST_RUN_DAILY_LIMIT`).

**Google 직접 호출로 바꾸려면** `LLM_BASE_URL` 을 비우고 `LLM_API_KEY` 에 Google AI Studio
키를 넣는다. 코드 변경은 없다.

## 2. SSAFY 블록체인 (체인 ID 31221)

| 항목 | 값 |
| --- | --- |
| 이름 | SSAFY |
| 체인 ID | **31221** |
| JSON-RPC | `https://rpc.ssafy-blockchain.com` |
| 네이티브 통화 | SSF (decimals 18) |
| 합의 | QBFT — 확정된 블록이 되돌려지지 않아 confirmation 1 이면 믿는다 |
| 블록 간격 | 약 10초 |
| 가스비 | **0**. EIP-1559 가 없어 레거시 트랜잭션 + `gasPrice 0` 으로 보낸다 |
| 블록 탐색기 | **없음** — 지갑에 체인을 추가할 때도 비워 둔다 |

**가입이 필요 없다.** 공개 RPC 라 키 없이 조회할 수 있다. 쓰기(출금 지급)에만 개인키가 든다.

**MetaMask 에 네트워크 추가** (시연 전 준비)

| 필드 | 값 |
| --- | --- |
| 네트워크 이름 | `SSAFY` |
| RPC URL | `https://rpc.ssafy-blockchain.com` |
| 체인 ID | `31221` |
| 통화 기호 | `SSF` |
| 블록 탐색기 | (비움) |

프론트가 `wallet_addEthereumChain` 으로 자동 추가를 제안하므로 보통 손으로 넣을 일은 없다.
다른 네트워크에 붙어 있으면 화면 상단에 배너가 뜨고, 버튼으로 전환한다.

**설정 위치**

- 백엔드 `client/blockchain/src/main/resources/blockchain.yml` — `ssafy.chain.rpc-url`
- 프론트 `frontend/src/lib/wagmi.ts` — `defineChain({ id: 31221, ... })`

> 문서에는 `wss` 주소만 있는데, 위 HTTPS 주소를 직접 호출해 같은 체인(31221)임을 확인했다.

## 3. SSAFY 토큰증권(STO) API

| 항목 | 값 |
| --- | --- |
| 베이스 URL | `https://sto.ssafy.io` |
| 변수 | `SSAFY_STO_BASE_URL` |

두 가지 토큰을 이 API 로 배포하고 다룬다.

### 3.1 abcToken — 이용권

| 항목 | 값 |
| --- | --- |
| 컨트랙트 | `0x56DC097C14836473f4Ad4BD675a3d01BE5e4C63c` |
| 표준 | ERC-1400 (토큰증권) |
| 변수 | `SSAFY_TOKEN_CONTRACT_ADDRESS` |
| 발행 스크립트 | `scripts/mint-abc-token.mjs` |

사용자가 이 토큰을 보관 지갑으로 보내면 백엔드가 체인에서 입금을 확인하고 ABC 를 적립한다.

| 지갑 | 주소 | 용도 |
| --- | --- | --- |
| 보관 지갑 (custody) | `0x64e72A170a7a36cE09806190Ed02085fe23CB6B6` | 충전 입금처 · 출금 지급처. **발행(오너·민터) 계정과 분리했다** |

관련 설정: `PAYMENT_CHARGE_CUSTODY_ADDRESS`, `PAYMENT_CHARGE_REQUIRED_CONFIRMATIONS=1`,
`PAYMENT_CHARGE_POLL_INTERVAL=10s`, `PAYMENT_CHARGE_VERIFICATION_TIMEOUT=30m`

### 3.2 에이전트 등기부 토큰 — 원본 증명

| 항목 | 값 |
| --- | --- |
| 컨트랙트 | `0xBBC46459B7A364089A924cf5C091e6CD9B5AB934` |
| 배포 | 2026-09-27, 블록 11376188, `scripts/deploy-agent-registry.mjs` |
| 주인 | 등기부 지갑 `0xFEAc…4f8C0` |
| 변수 | `SSAFY_AGENT_REGISTRY_CONTRACT_ADDRESS` · `SSAFY_AGENT_REGISTRY_SIGNER_PRIVATE_KEY` |

발행은 하지 않고, **문서 칸에 에이전트 버전마다 원작자와 메타데이터 해시를 적는다.**
토큰증권 API 는 거래가 블록에 적힐 때까지 기다렸다 답하므로 타임아웃을 30초로 둔다
(`SSAFY_AGENT_REGISTRY_WRITE_TIMEOUT`).

## 4. MetaMask

| 항목 | 값 |
| --- | --- |
| 연결 방식 | wagmi `injected({ target: 'metaMask' })` |
| WalletConnect | **쓰지 않는다** — RainbowKit 을 걷어내 `projectId` 발급이 필요 없다 |
| 연결 대화상자 | 자체 구현 (`frontend/src/components/wallet-dialog.ts`) |

**로그인 흐름**: 지갑 연결 → 백엔드가 nonce 가 든 메시지 발급 → MetaMask 로 서명 →
백엔드가 서명을 검증하고 세션 쿠키 발급(Spring Session JDBC).

- 서명 메시지에 `WALLET_AUTH_DOMAIN` · `WALLET_AUTH_URI` · `WALLET_AUTH_CHAIN_ID(31221)` 가
  들어간다. 접속 주소와 다르면 로그인이 거절된다.
- 메시지 유효 시간 5분(`WALLET_AUTH_MESSAGE_TTL`), 세션 2시간(`AUTH_SESSION_TIMEOUT`).
- `target: 'metaMask'` 를 지정하지 않으면 `window.ethereum` 을 선점한 다른 지갑 확장을 잡는다.

**시연 전 준비**: 브라우저에 MetaMask 설치 → SSAFY 네트워크 추가 → 계정에 abcToken 충전
(`scripts/mint-abc-token.mjs` 로 발행해 넣는다).

## 5. 그 밖

| 서비스 | 내용 |
| --- | --- |
| **GitLab (lab.ssafy.com)** | 저장소 · CI/CD. Runner 를 배포 서버에 shell executor 로 등록하므로 **SSH 키·배포용 시크릿이 없다.** 등록 토큰은 Settings > CI/CD > Runners 에서 확인 |
| **Docker Hub / ghcr.io** | 베이스 이미지 `mysql:8.4` · `eclipse-temurin:25-{jdk,jre}` · `node:24` · `python:3.12-slim` · `ghcr.io/astral-sh/uv:python3.11-bookworm-slim`. 익명 pull (rate limit 주의) |
| **PyPI · Maven Central · npm** | 의존성. 추천 엔진의 torch 만 `https://download.pytorch.org/whl/cpu` 에서 CPU 휠로 받는다 (CUDA 가 딸려오면 이미지가 2.5GB 를 넘는데 EC2 에 GPU 가 없어 전부 죽은 용량) |
| **Hugging Face** | 추천 엔진이 `jhgan/ko-sroberta-multitask` 기반 파인튜닝 모델을 쓴다. 운영 컨테이너는 **`HF_HUB_OFFLINE=1`** 로 네트워크를 끊고 볼륨의 가중치만 쓴다 — 계정 불필요 |
| **Let's Encrypt** | `certbot --nginx` 로 HTTPS 인증서 발급 |
| **Jira · Confluence** | 프로젝트 관리용. 서비스 런타임과 무관 |

## 6. 지갑 · 개인키 정리

세 개의 지갑이 서로 다른 일을 한다. **개인키는 모두 서버의 `backend.env` 또는 GitLab
Masked Variable 에만 두고, 저장소 · 채팅 · 이슈에 붙이지 않는다.**

| 지갑 | 주소 | 하는 일 | 개인키 변수 | 스위치 |
| --- | --- | --- | --- | --- |
| 보관 지갑 | `0x64e7…B6B6` | 충전 입금 받기, 출금 지급 보내기 | `SSAFY_CHAIN_SIGNER_PRIVATE_KEY` | `PAYMENT_WITHDRAWAL_PAYOUT_ENABLED` |
| 등기부 지갑 | `0xFEAc…4f8C0` | 에이전트 원본 증명 기록 | `SSAFY_AGENT_REGISTRY_SIGNER_PRIVATE_KEY` | `AGENT_PROVENANCE_REGISTRATION_ENABLED` |
| 발행(오너) 지갑 | – | abcToken 발행 | 저장소에 없음 (`scripts/mint-abc-token.mjs` 실행 시 주입) | – |
| 관리자 지갑 | – | 본인 확인 · 출금 심사 | 개인키 아님, **주소만** | `ADMIN_WALLET_ADDRESSES` |

**키를 넣지 않아도 서비스는 뜬다.** 대신 해당 기능이 조용히 멈춘다.

| 상태 | 결과 |
| --- | --- |
| 보관 지갑 키 없음 | 관리자가 승인해도 출금이 `APPROVED` 에서 멈추고 체인으로 나가지 않는다 |
| 등기부 키 없음 | 에이전트를 공개해도 원본 증명이 `PENDING` 으로 쌓이기만 한다 (조회는 된다) |
| 관리자 주소 없음 | `/api/v1/admin/**` 를 부를 수 있는 사람이 없어 심사가 불가능하다 |

오류가 아니라 **설계된 동작**이다. 키 없이 시연할 때는 이 점을 미리 알고 있어야 한다.

### 운영 서버 현재 상태 (2026-09-28 확인)

| 항목 | 상태 |
| --- | --- |
| `SSAFY_CHAIN_SIGNER_PRIVATE_KEY` | **설정됨** (64자) |
| `PAYMENT_WITHDRAWAL_PAYOUT_ENABLED` | **`true`** |
| `SSAFY_AGENT_REGISTRY_SIGNER_PRIVATE_KEY` | **설정됨** (64자) |
| `AGENT_PROVENANCE_REGISTRATION_ENABLED` | **`true`** |
| `ADMIN_WALLET_ADDRESSES` | **설정됨** (주소 1개) |
| `AI_SERVICE_TOKEN` | **설정됨** |

⇒ **시연에서 승인한 출금은 실제로 체인에 나가고, 공개한 에이전트는 등기부에 기록된다.**
되돌릴 수 없는 동작이니 리허설 때 주의한다.

## 7. 서비스 간 인증 — `X-ABC-Service-Token`

백엔드와 AI 두 서비스는 같은 Docker 네트워크 안에서만 닿고, 공유 토큰 하나로 서로를 확인한다.

```
백엔드  AI_SERVICE_TOKEN   ──┐
                              ├── 같은 값이어야 한다 → 헤더 X-ABC-Service-Token
AI      ABC_SERVICE_TOKEN  ──┘
```

- 백엔드는 토큰이 비어 있으면 **헤더를 붙이지 않고 기동 때 경고**를 남긴다.
- AI 쪽도 비어 있으면 **검사를 건너뛴다.** 양쪽 다 비면 인증 없이 조용히 뜨므로,
  `ai:deploy` 가 배포 전에 빈 값을 잡아 실패시킨다.
