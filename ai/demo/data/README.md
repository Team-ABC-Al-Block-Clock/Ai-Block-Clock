# 시연 데이터 사전 (S15P21A403-273)

> ⚠ **이 문서의 필드명 · 엑셀 열 이름은 잠정값이다.**
> 스키마 필드 정의는 트랙 A 영역이다. `ai/schemas/catalog/*.json` 이 확정되면
> 그 한국어 라벨에 맞춰 `generate_demo_data.py` 를 고치고 데이터를 다시 만든다 (09-19).
> 지금 값은 그 전까지 쓰는 자리표시다.

시연 워크플로우의 첫 입력이 되는 합성 성적 데이터다.
**실제 학생 정보는 쓰지 않았다.** 이름 · 점수 · 출결 전부 생성값이다.

| 파일 | 내용 |
| --- | --- |
| `demo_roster_down.xlsx` | **시연 본편 입력.** 원장이 업로드하는 엑셀 |
| `demo_roster_up.xlsx` | 반대 분기 확인용 엑셀 |
| `demo_roster_*.json` | 위 엑셀을 H2A가 파싱했을 때 나와야 하는 `edu.roster@1` |
| `demo_analysis_*.json` | 분석 노드가 내야 하는 `edu.analysis@1` — **수치 정합성 기준값** |

`.json` 은 H2A · 분석 노드의 **정답지**다. 구현이 이 값과 다르면 구현이 틀린 것이다.

---

## 1. 두 벌인 이유 — 분기

| 파일 | 전체 평균 | `avg_delta` | 타는 분기 | 학생 추세 |
| --- | --- | --- | --- | --- |
| `down` | 74.26 → 68.86 | **−5.40** | **경고형** ← 시연 본편 | 하락 16 · 상승 4 |
| `up` | 74.58 → 79.54 | +4.96 | 격려형 | 하락 4 · 상승 16 |

```
edu.analysis@1 의 summary.avg_delta < 0  →  경고형 가정통신문 노드
그 외                                     →  격려형 가정통신문 노드
```

**두 파일은 학생 명단과 과목이 같고 점수만 다르다.** 결과가 달라진 이유를 분기
하나로 설명할 수 있어야 하기 때문이다. 명단까지 다르면 무엇 때문에 달라졌는지 못 가린다.

**전원이 같은 방향으로 움직이지는 않는다.** `down` 에도 오른 학생이 4명 있다.
20명이 전부 떨어지는 데이터는 현실감이 없고, 편지가 학생마다 달라지는 것도 못 보여준다.
→ 경고형 노드가 이 4명에게는 격려형 편지를 써야 한다 (`letters[].tone`).

## 2. 엑셀 열 구성

`demo_roster_down.xlsx` · 시트명 `성적` · 1행이 헤더, 2행부터 학생 한 명씩 20행.

| 열 | 예시 | 의미 |
| --- | --- | --- |
| `학생명` | 강윤슬 | 학생 이름 (생성값) |
| `국어(이번달)` | 66 | 이번 달 점수, 0~100 정수 |
| `국어(지난달)` | 57 | 지난 달 점수, 0~100 정수 |
| `영어(이번달)` · `영어(지난달)` | | 이하 동일 |
| `수학(이번달)` · `수학(지난달)` | | |
| `과학(이번달)` · `과학(지난달)` | | |
| `출석` | 19 | 이번 달 출석 일수 |
| `결석` | 2 | 이번 달 결석 일수 |

과목 순서는 **국어 · 영어 · 수학 · 과학** 고정. 기간은 **2026-07 → 2026-08**.

> **열 이름은 협상 가능하다.** H2A 파서(`S15P21A403-259`)에 맞추는 게 우선이니,
> 다른 형태가 편하면 알려주면 `generate_demo_data.py` 를 고쳐 다시 만든다.

### 엑셀에 없고 별도로 들어가는 것 — 원장 코멘트

엑셀과 함께 화면에서 입력받는 자연어 한 줄이다. `edu.roster@1` 의
`context.comment` 로 들어간다.

```
이번 달 전체적으로 성적이 좀 떨어졌어요. 학부모님들께 보낼 안내문에
너무 겁주지는 말고, 그래도 지금 잡아야 한다는 건 분명히 전해주세요.
```

**H2A는 이 문장을 가공하지 않고 그대로 통과시킨다** (팀 합의 N-3: H2A는 LLM을 쓰지 않는다).
가공하려 들면 원장의 의도가 뭉개지고, 그 뭉개진 문장이 편지 20통의 톤을 좌우하게 된다.

`up` 쪽 코멘트는 `demo_roster_up.json` 안에 있다.

## 3. `edu.roster@1` — H2A 출력

```jsonc
{
  "schema_id": "edu.roster@1",
  "period":   { "current": "2026-08", "previous": "2026-07" },
  "subjects": ["국어", "영어", "수학", "과학"],
  "students": [
    {
      "name": "강윤슬",
      "scores": {
        "국어": { "current": 66, "previous": 57 },
        "영어": { "current": 69, "previous": 65 }
        // 과목 4개
      },
      "attendance": { "present": 19, "absent": 2 }
    }
    // 학생 20명
  ],
  "context": { "comment": "이번 달 전체적으로 성적이 좀 떨어졌어요. …" }
}
```

`students` 순서는 엑셀 행 순서를 유지한다. 뒤 노드들이 같은 순서를 전제한다.

## 4. `edu.analysis@1` — 분석 노드 출력

```jsonc
{
  "summary": {
    "student_count": 20,
    "avg_current":  68.86,
    "avg_previous": 74.26,
    "avg_delta":    -5.40      // ★ 분기 조건
  },
  "students": [
    { "name": "강윤슬", "avg_current": 72.25, "avg_delta": 6.50,
      "weak_subject": "과학", "trend": "up" }
  ],
  "subjects": [
    { "name": "국어", "avg_current": 69.75, "avg_delta": -4.55 }
  ]
}
```

### 계산 규칙

| 값 | 규칙 |
| --- | --- |
| 학생 평균 | 그 학생의 전 과목 점수 합 ÷ 과목 수 |
| 전체 평균 | 모든 학생의 모든 과목 점수 합 ÷ (학생 수 × 과목 수) |
| `*_delta` | `current − previous`, 소수 둘째 자리 반올림 |
| `weak_subject` | 그 학생의 이번 달 최저 점수 과목. 동점이면 `subjects` 앞쪽 |
| `trend` | `avg_delta >= 1.0` → `up` · `<= -1.0` → `down` · 그 사이 → `flat` |

**이 규칙은 `ai/demo/analysis_reference.py` 와 `ai/prompts/analysis_node.md` 에도
같은 내용으로 들어 있다. 한 곳을 고치면 세 곳을 같이 고쳐야 한다.**

## 5. 다시 만들기 · 검증하기

```bash
cd ai/demo

# 데이터 재생성 — seed 고정이라 몇 번을 돌려도 같은 숫자가 나온다
python generate_demo_data.py          # pandas · openpyxl 필요

# 분석 기대값 계산
python analysis_reference.py

# 구현 출력이 기대값과 맞는지 (S15P21A403-272 수치 정합성 가드)
python analysis_reference.py --check <구현이_낸_analysis.json>
```

seed 를 고정한 이유는 리허설 3회(W4 수) 때문이다. 매번 숫자가 바뀌면
"저번엔 이랬는데"가 통하지 않는다.

## 6. 알려진 한계

- **학생 20명은 시연용 하한이다.** 실제 학원은 더 많고, 토큰 투입 전략(AI-05-4)을
  다시 재야 할 수 있다. 시연 범위에서는 20명으로 충분하다는 판단이다
- **과목 4개 고정.** 과목 수가 달라지는 경우는 다루지 않는다
- **결석이 통계에 반영되지 않는다.** `attendance` 를 받아만 두고 `edu.analysis@1` 은
  쓰지 않는다. 출결까지 분석에 넣으면 스키마가 커지는데 시연에서 보여줄 자리가 없다
