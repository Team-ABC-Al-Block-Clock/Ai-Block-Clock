# 시연용 사용자 사진 — 최사장이 실행할 때 올리는 파일

| 파일 | 누가 · 언제 | 어느 노드가 보나 |
| --- | --- | --- |
| `소소칫솔_시제품.jpg` | 사용자, 실행 화면에서 브리프와 함께 올린다 | **모든 LLM 노드**(계약 §7.1). 특히 ② 제품 분석(강점 · 약점 근거) · ⑥ 광고 카피(사진에서 보이는 것 한 줄 이상) |

사진은 실제 칫솔(대나무 손잡이면 가장 좋다)을 폰으로 찍어 이 폴더에 위 이름으로 넣는다. 저작권 문제가 없는 직접 촬영본만.
5MB 안쪽(폰 원본이면 크기를 줄인다 — 합계 10MB 상한). 파일이 없으면 실행은 사진 없이 돈다(프롬프트가 사진 부재를 언급하지 않는다).

```bash
cd ai/spike/linear-mvp
uv run python -m src.runner --workflow brand_agent --input ../../demo/brand/brief_high.json \
    --file ../../demo/brand/photos/소소칫솔_시제품.jpg --ref n4=../../demo/brand/ref/보고서_디자인_참고.png
```
