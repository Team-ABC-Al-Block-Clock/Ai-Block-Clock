# 브랜딩 시연 데이터 — 브리프 2종 (S15P21A403-276)

`biz.brand_brief@1` 형식의 합성 입력이다. 실제 기업·제품이 아니다.
파일은 스키마 속성만 담는다 (`schema_id` 같은 메타는 넣지 않는다 — 검증에서 걸린다).

| 파일 | 카테고리 | 기대 `competition_level` | 타는 분기 |
| --- | --- | --- | --- |
| `brief_high.json` | 칫솔 | **high** | ③a 차별화 전략 |
| `brief_low.json` | 클라이밍용 손가락 보호 테이프 | **low** | ③b 대중 공략 전략 |

## 왜 두 벌인가

`biz.market_research@1` 의 `competition_level` 이 워크플로우의 **분기 조건**이다.

```
competition_level == "high"  →  ③a 차별화 전략
competition_level == "low"   →  ③b 대중 공략 전략
```

한 벌만 있으면 분기가 갈라지는 걸 시연에서 못 보여준다. 두 카테고리의 **경쟁 밀도만
크게 다르게** 잡았고, 나머지 항목(고객·가격대·차별점)은 비슷한 수준으로 채웠다.
결과가 달라진 이유를 분기 하나로 설명할 수 있어야 하기 때문이다.

## 카테고리를 이렇게 고른 이유

판정 규칙(`ai/prompts/brand/01_market_research.md`)은 **`competitors` 배열이 5칸을
다 차는가**를 경계로 삼는다. 두 브리프는 그 경계에서 멀리 떨어져 있어야 10회를 돌려도
값이 흔들리지 않는다.

- **칫솔** — 대형마트 진열대에 기성 브랜드가 열 개 가까이 놓인다. 5칸이 쉽게 찬다
- **클라이밍용 손가락 테이프** — 국내 일반 유통 브랜드를 5개 대는 것이 사실상 불가능하다

### 09-22 교체 — 반려견 LED 하네스에서 바꿨다

처음 low 브리프는 "반려견 야간 산책용 LED 하네스"였다. 09-22 실호출에서 **high 로
판정돼 차별화 경로를 탔다.** 모델이 전국 유통 브랜드 5개를 댈 수 있다고 본 것이다.

경계에서 멀다고 판단한 것이 틀렸다. 반려동물 용품은 대형 유통 채널에 이미 자리를
잡은 카테고리였다. **더 좁은 취미 장비로 바꿨다** — 클라이밍 용품은 전문점과 해외
직구 위주라 일반 유통 브랜드를 5개 대기 어렵다.

경계에 가까운 카테고리를 고르면 호출마다 값이 뒤집힌다.
**경계 근처를 피하는 것 자체가 설계다.**

## `comment` 를 넣은 이유

`comment` 는 선택 항목이지만 두 브리프 모두 채웠다. 뒤쪽 노드(④ 보고서, ⑥ 카피)가
**사용자의 요청을 실제로 반영하는지** 볼 수 있어야 하기 때문이다. 둘 다 "이렇게는
쓰지 말아 달라"는 금지형 요청을 담았다 — 지켰는지 안 지켰는지가 눈으로 갈린다.

## 준수율 측정에 쓰는 법

```bash
cd ai/demo
python check_compliance_brand.py --node 01 --brief brand/brief_high.json --runs 10 --expected-level high
```

`competition_level` 이 10회 중 10회 같은 값이어야 한다 (로드맵 §3 기준).

설치·입력 형식·오프라인 검사·결과 해석은 [준수율 검사 안내](COMPLIANCE.md)를 참고한다.
