# ③a 차별화 전략 프롬프트 — 경쟁 high 경로 (S15P21A403-276)

| 항목 | 내용 |
| --- | --- |
| 노드 | 브랜딩 전략 에이전트 1단계 · 분기 A |
| 입력 → 출력 | `{ market: biz.market_research@1, product: biz.product_analysis@1 }` → `biz.strategy_draft@1` |
| 발동 조건 | `market.competition_level == "high"` |
| 짝 | ③b 대중 공략 (`low` 경로). **출력 스키마가 같다** |
| 기준 | 스키마 통과율 ≥ 95% · `approach` 가 항상 `"차별화"` |

---

## 1. ③a 와 ③b 는 출력이 같다 — `approach` 만이 구분점

두 노드는 같은 `biz.strategy_draft@1` 를 낸다. 그래야 ④ 보고서가 **어느 쪽이 왔든
같은 방식으로 받을 수 있다**(합류 조건).

문제는 합류한 뒤에 ④가 "어느 길로 왔는지" 알 방법이 없다는 것이다. 그래서 스키마에
`approach` 가 있다.

```
③a  →  approach = "차별화"
③b  →  approach = "대중 공략"
```

**이 값은 판단하는 게 아니라 고정이다.** ③a 는 경쟁 high 일 때만 발동하므로 언제나
"차별화"다. 모델이 내용을 보고 "이건 대중 공략 같은데" 하고 바꾸면 안 된다.
시연에서 분기가 갈렸다는 증거가 이 필드 하나뿐이다.

## 2. 이 노드가 받는 것 — 처음으로 둘을 같이 본다

①(시장)과 ②(제품)가 여기서 합쳐진다. **비교가 가능해지는 첫 지점**이다.
②는 비교 표현을 금지당했지만 여기서는 그게 본업이다.

## 3. 프롬프트

<!-- prompt:system -->
```
당신은 브랜드 전략가다. 시장 조사 결과와 제품 분석 결과를 함께 받아 전략 초안을 작성한다.

[전제 — 바꾸지 않는다]
이 요청은 경쟁이 치열한 카테고리로 판정되어 배정됐다.
따라서 approach 는 반드시 "차별화" 다. 내용을 보고 다시 판단하지 않는다.

[차별화 전략이란 무엇인가]
모두와 같은 말을 더 크게 하는 대신, **경쟁사가 비어 둔 자리를 찾아 거기에 선다.**
- 이미 여러 브랜드가 말하고 있는 것은 우리의 중심 메시지로 쓰지 않는다.
- 제품 분석의 약점을 숨기지 않는다. 비켜 가거나, 그 약점이 문제가 되지 않는
  고객층으로 범위를 좁힌다.
- 시장 전체를 노리지 않는다. 좁혀서 이기는 그림을 그린다.

[각 항목 작성 지침]
- approach: "차별화" 로 고정한다.

- positioning: 한 문장. "누구에게 무엇으로 기억되는 브랜드인가"를 담는다.
  경쟁사 중 누구의 자리와도 겹치지 않아야 한다.
  시장 조사의 competitors[].positioning 을 먼저 훑고, 그중 어느 것과도 다른 자리를 잡는다.

- rationale_md: 왜 이 자리인지 3~5문장. 마크다운 허용.
  반드시 두 가지를 근거로 든다.
    (1) 시장 조사에서 — 어느 경쟁사가 무엇을 이미 차지하고 있어서 그 자리를 피했는지
    (2) 제품 분석에서 — 우리 강점 중 무엇이 이 자리를 뒷받침하는지
  약점을 하나 골라 어떻게 다룰지도 한 문장으로 적는다.

- core_strategies: 3~5개. label 은 5~15자 명사구, detail 은 실행 단위로 한 문장.
  "브랜드 인지도를 높인다" 처럼 누구에게나 해당하는 문장은 쓰지 않는다.
  무엇을 하겠다는 것인지 읽고 바로 그림이 그려져야 한다.

[하지 않을 것]
- 숫자를 지어내지 않는다. 받은 두 입력에 없는 수치는 쓰지 않는다.
- 경쟁사를 깎아내리지 않는다. 자리를 구분하는 것이지 우열을 매기는 게 아니다.
- 채널·예산·일정은 여기서 정하지 않는다 (2단계 ⑤⑦의 몫이다).
```

## 4. 채점 기준

| # | 항목 | 실패 조건 |
| --- | --- | --- |
| ① | **분기 표식** | `approach` 가 `"차별화"` 가 아님 |
| ② | 항목 수 | `core_strategies` 가 3~5개를 벗어남 |
| ③ | 근거 누락 | `rationale_md` 에 시장 조사의 경쟁사명이 하나도 등장하지 않음 |
| ④ | 포지션 충돌 | `positioning` 이 `competitors[].positioning` 중 하나와 거의 같음 |
| ⑤ | 공허한 전략 | `core_strategies[].detail` 에 "인지도", "브랜드 가치 제고", "적극 활용" 등장 |
| ⑥ | 월권 | 채널명·예산·일정이 등장 (⑤⑦의 영역) |
| ⑦ | 지어낸 수치 | 두 입력에 없는 숫자가 등장 |

**①이 대표 지표다.** 이 값이 틀리면 ④ 보고서가 어느 경로였는지 잃어버린다.
