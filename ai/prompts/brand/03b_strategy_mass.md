# ③b 대중 공략 전략 프롬프트 — 경쟁 low 경로 (S15P21A403-276)

| 항목 | 내용 |
| --- | --- |
| 노드 | 브랜딩 전략 에이전트 1단계 · 분기 B |
| 입력 → 출력 | `{ market: biz.market_research@1, product: biz.product_analysis@1 }` → `biz.strategy_draft@1` |
| 발동 조건 | `market.competition_level == "low"` |
| 짝 | ③a 차별화 (`high` 경로). **출력 스키마가 같다** |
| 기준 | 스키마 통과율 ≥ 95% · `approach` 가 항상 `"대중 공략"` |

> ③a 와 같은 형식으로 낸다. 두 문서를 나란히 두고 고친다 —
> **한쪽만 고치면 합류 지점에서 모양이 어긋난다.**

---

## 1. `approach` 는 고정이다

```
③a  →  approach = "차별화"
③b  →  approach = "대중 공략"      ← 이 문서
```

경쟁 low 일 때만 발동하므로 언제나 "대중 공략"이다. 내용을 보고 다시 판단하지 않는다.
자세한 이유는 `03a_strategy_differentiate.md` 1절과 같다.

## 2. 차별화와 무엇이 다른가

경쟁이 적은 시장은 **자리를 다투는 게 아니라 시장 자체가 아직 작다.**
그래서 문제가 뒤집힌다.

| | ③a 차별화 (high) | ③b 대중 공략 (low) |
| --- | --- | --- |
| 싸우는 대상 | 경쟁 브랜드 | **"굳이 필요한가"라는 무관심** |
| 목표 | 좁혀서 이기기 | 넓혀서 선점하기 |
| 첫 과제 | 남과 다르게 보이기 | **이 물건이 왜 필요한지 납득시키기** |

경쟁사가 적다는 건 유리한 게 아니라 **아무도 이 카테고리를 설명해 주지 않았다**는 뜻이다.
고객은 비슷한 제품 중에 고르는 게 아니라, 아예 안 사는 쪽과 저울질한다.

## 4. 채점 기준

| # | 항목 | 실패 조건 |
| --- | --- | --- |
| ① | **분기 표식** | `approach` 가 `"대중 공략"` 이 아님 |
| ② | 항목 수 | `core_strategies` 가 3~5개를 벗어남 |
| ③ | 근거 누락 | `rationale_md` 에 시장 조사의 `trends` 항목이 하나도 반영되지 않음 |
| ④ | **필요성 전략 누락** | `core_strategies` 중 "왜 필요한지 알리는" 항목이 없음 (사람 확인) |
| ⑤ | 공허한 전략 | `core_strategies[].detail` 에 "인지도", "브랜드 가치 제고", "적극 활용" 등장 |
| ⑥ | 월권 | 채널명·예산·일정이 등장 (⑤⑦의 영역) |
| ⑦ | 없는 경쟁사 | 시장 조사에 없던 브랜드명이 등장 |

**①이 대표 지표다.** ③a 와 같은 이유다.
④는 자동 판정이 어려워 사람이 확인한다 — 이 경로의 성격을 지켰는지 보는 항목이라
빠뜨리면 ③a 와 구분이 안 되는 결과가 나온다.
