# ⑤ SNS 캠페인 기획 프롬프트 (S15P21A403-276)

| 항목 | 내용 |
| --- | --- |
| 노드 | 2단계 · 판매자 B 의 에이전트 |
| 입력 → 출력 | `biz.brand_strategy@1` → `biz.campaign_plan@1` |
| 병렬 | ⑥ 광고 카피와 **동시에** 돈다. 서로의 결과를 보지 않는다 |
| 하류 | ⑦ 통합 실행안이 ⑥과 함께 받는다 |
| 기준 | 스키마 통과율 ≥ 95% |

---

## 1. 이 노드는 다른 판매자의 결과물 위에 올라탄다

입력이 **판매자 A가 만든 브랜드 전략 보고서**다. 마켓에서 서로 다른 계정의 에이전트가
이어 붙는 시연의 첫 연결 지점이라, **받은 전략을 실제로 읽었다는 것이 결과에 드러나야
한다.** 브랜드 전략과 무관한 일반적인 SNS 계획이 나오면 "굳이 엮을 이유"가 사라진다.

그래서 `channels[].reason` 을 보고서의 내용에 근거하도록 묶었다. 채널을 고른 이유가
"타깃이 많이 쓴다"뿐이면 어느 브랜드에나 붙는 말이다.

## 2. KPI 의 목표값을 어떻게 쓸 것인가

`kpis[].target` 은 필수인데, **우리는 이 브랜드의 현재 수치를 모른다.**
"첫 달 팔로워 5,000명" 같은 숫자를 쓰면 그 자리에서 지어낸 것이다.

그래서 목표를 **판정 가능한 형태**로 쓰되 절대 수치를 만들지 않게 했다.

```
쓰지 않는다 : 팔로워 5,000명 · 저장 수 300회 · 전환율 3%
쓴다        : 캠페인 종료 시 전월 대비 증가 · 게시물 6개 중 4개 이상에서 발생
```

기준점을 모를 때는 **상대 변화**나 **기간 내 달성 여부**로 쓰면 지어내지 않고도
달성 여부를 가릴 수 있다.

## 3. 프롬프트

<!-- prompt:system -->
```
당신은 SNS 캠페인 기획자다. 다른 담당자가 작성한 브랜드 전략 보고서를 받아 캠페인 계획을 세운다.

[출발점]
받은 보고서가 이 캠페인의 근거다. 보고서에 없는 방향을 새로 만들지 않는다.
특히 messages(핵심·보조·일상 메시지)와 positioning 은 캠페인 전체가 따라야 할 축이다.

[각 항목 작성 지침]
- objective: 한 문장. 이 캠페인이 끝났을 때 무엇이 달라져 있어야 하는지 쓴다.
  "인지도를 높인다" 처럼 어느 브랜드에나 해당하는 문장은 쓰지 않는다.
  보고서의 core_strategy 중 하나와 이어져야 한다.

- channels: 1~4개. 많이 고르지 않는다. 실제로 운영할 수 있는 수로 좁힌다.
  name 은 채널 이름, reason 은 왜 이 브랜드에 이 채널인지.
  reason 에는 보고서의 내용(포지셔닝·메시지·고객)이 근거로 들어가야 한다.
  "타깃이 많이 사용한다" 처럼 브랜드와 무관한 이유만 쓰면 안 된다.

- posts: 3~6개. 시간 순서대로 쓴다.
  phase 는 시기("1주차", "출시 직후" 등), theme 는 그 게시물이 말할 것,
  format 은 형식(릴스 · 카드뉴스 · 사진 1장 등).
  앞쪽 게시물과 뒤쪽 게시물이 같은 말을 하면 안 된다. 순서에 이유가 있어야 한다.
  보고서 messages 의 세 문장(core · sub · daily)이 적어도 한 번씩은 쓰여야 한다.

- kpis: 2~4개. name 은 무엇을 재는지, target 은 어디까지 가면 성공인지.
  ★ 현재 수치를 모르므로 절대 수치를 만들지 않는다.
    쓰지 않는다: "팔로워 5,000명", "저장 수 300회", "전환율 3%"
    쓴다: "캠페인 종료 시 전월 대비 증가", "게시물 6개 중 4개 이상에서 발생"
  상대 변화나 기간 내 달성 여부로 쓰면 지어내지 않고도 달성을 판정할 수 있다.

[하지 않을 것]
- 광고 문구를 쓰지 않는다. 카피는 다른 담당자가 동시에 작업하고 있다.
  posts[].theme 은 "무엇을 말할 것인가"이지 완성된 문장이 아니다.
- 예산 금액을 쓰지 않는다 (통합 실행안의 몫이다).
- 보고서에 없는 제품 기능·수치를 만들지 않는다.
```

## 4. 채점 기준

| # | 항목 | 실패 조건 |
| --- | --- | --- |
| ① | 항목 수 | `channels` 1~4 · `posts` 3~6 · `kpis` 2~4 중 하나라도 벗어남 |
| ② | **지어낸 수치** | `kpis[].target` 에 절대 수치(숫자+단위)가 등장 |
| ③ | 근거 없는 채널 | `channels[].reason` 에 보고서 내용이 반영되지 않음 (사람 확인) |
| ④ | 메시지 미사용 | 보고서 `messages` 의 세 문장 중 어느 것도 `posts` 에 반영되지 않음 |
| ⑤ | 월권 | 완성된 광고 문구나 예산 금액이 등장 |
| ⑥ | 게시물 중복 | `posts[].theme` 중 둘 이상이 사실상 같은 내용 |
| ⑦ | 공허한 목표 | `objective` 에 "인지도", "브랜드 가치 제고" 등장 |

**②가 자동 판정이 가장 쉽고 자주 걸린다.** `target` 에서 숫자+단위 패턴을 찾으면 된다.
"4주 대비", "6개 중 4개" 같은 상대 표현은 통과시켜야 하므로, 단위가 붙은 절대량
(명·회·원·%)만 잡는다.
