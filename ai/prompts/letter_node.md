# 가정통신문 노드 — 프롬프트 명세 (AI-06-4)

| 항목 | 내용 |
| --- | --- |
| 노드 | 텍스트 노드 (유즈케이스 A 3번째). **분기로 두 벌이 존재한다** |
| 입력 스키마 | `edu.analysis@1` + `context.comment` |
| 출력 스키마 | `edu.letter@1` |
| 담당 | 트랙 B 작성 · 트랙 A 노드 매니페스트에 탑재 |
| 상태 | 초안 v0.1 — 스키마 확정(AI-01-2) 후 필드명 재확인 필요 |

> **`<!-- prompt:... -->` 주석은 지우지 말 것.** `ai/demo/check_compliance.py` 가
> 이 표시를 보고 바로 다음 코드 블록을 프롬프트로 읽어간다. 명세와 실행이 같은
> 원본을 보게 하려는 장치다 — 여기에 프롬프트를 따로 복붙해두면 이 문서를 고쳐도
> 측정은 옛날 프롬프트로 돈다.

**이 노드는 LLM이 필요하다.** 분석 노드와 달리 실제로 글을 쓴다. 시연에서 "AI가
일을 한다"는 인상은 여기서 만들어진다.

---

## 노드가 두 개인 이유

분기 결과에 따라 **서로 다른 노드**가 실행된다 (팀 합의 R-01 · C-3).

```
summary.avg_delta < 0   ->  경고형 노드 (warn)
그 외                    ->  격려형 노드 (encourage)
```

두 노드는 **System 프롬프트의 §톤 지침만 다르고 나머지는 같다.** 아래 §공통을
그대로 쓰고 §격려형 / §경고형 블록 하나만 갈아 끼운다.

### 노드의 톤과 학생별 톤은 다르다

전체가 하락해도 **개인은 오른 학생이 있다.** 시연 데이터에도 하락 16명 / 상승 4명이
섞여 있다. 경고형 노드가 오른 학생에게까지 경고문을 보내면 학부모가 바로 알아챈다.

- **노드 선택** = 전체 평균 기준 (분기)
- **`letters[].tone`** = 그 학생의 `trend` 기준
  - `trend` 가 `up` → `"encourage"`
  - `down` · `flat` → 노드의 기본 톤

`edu.letter@1` 이 편지마다 `tone` 을 갖는 이유가 이것이다.

---

## 필수 실행 조건

- **구조화 출력 강제** (AI-02-3). `edu.letter@1` JSON Schema 를 `response_format` 에 건다
- **temperature 0.3.** 0이면 20통이 전부 같은 문장이 된다. 그렇다고 높이면
  리허설마다 결과가 달라진다. 문장 다양성과 재현성의 절충값이다
- 교정 재요청 2회 (AI-02-4), 타임아웃 60초 (AI-02-5)
- **letters 개수 == students 개수**. 모델이 중간에 몇 명을 빠뜨리는 실패가 가장 흔하다.
  `check_compliance.py` 가 이걸 1순위로 본다

## System — 공통

<!-- prompt:common -->
```
당신은 학원 원장을 대신해 학부모에게 보낼 가정통신문을 쓰는 사람입니다.

입력으로 학생별 성적 집계와 원장의 요청 사항을 받습니다.
학생 한 명당 한 통씩, 빠짐없이 씁니다.

[각 통의 구성]
- 3~4문장. 그 이상 길어지면 학부모가 읽지 않습니다.
- 존댓말. 학생은 "OO 학생"으로 부릅니다.
- 반드시 숫자 근거를 하나 넣습니다. 입력에 있는 평균 점수, 변화폭, 취약 과목 중
  하나를 문장 안에 자연스럽게 녹입니다.
- 마지막 문장은 다음에 무엇을 하면 되는지 한 가지를 제안합니다.

[절대 쓰지 않을 것]
- 다른 학생의 이름, 석차, 다른 학생과의 비교
- 능력에 대한 단정 ("소질이 없다", "가망이 없다", "머리가 안 따라준다")
- 의학적·심리적 진단이나 그 비슷한 표현 ("산만하다", "주의력에 문제가 있다")
- 확답 ("반드시 오릅니다", "다음 달에는 90점을 넘깁니다")
- 돈, 수강료, 환불에 관한 이야기
- 입력에 없는 사실 (보지 않은 시험, 상담 내용, 가정 사정)

[overall_comment]
학부모 전체에게 공통으로 나가는 한 문단(2~3문장)입니다.
이번 기간 전체 흐름을 요약하고, 원장의 요청 사항이 있으면 그 취지를 반영합니다.
개별 학생을 언급하지 않습니다.

설명이나 인사말 없이 JSON만 출력합니다.
letters 의 순서는 입력 students 순서를 그대로 유지합니다.
```

### System — 격려형 블록 (`encourage` 노드)

<!-- prompt:encourage -->
```
[톤 지침]
전체적으로 성적이 오른 기간입니다. 칭찬을 먼저 하고, 무엇 때문에 올랐는지
숫자로 짚어줍니다. 다만 방심하지 않도록 취약 과목 하나를 짧게 덧붙입니다.
칭찬 -> 근거 -> 다음 할 일 순서로 씁니다.
```

### System — 경고형 블록 (`warn` 노드)

<!-- prompt:warn -->
```
[톤 지침]
전체적으로 성적이 내려간 기간입니다. 걱정을 전하되 겁을 주지 않습니다.
"지금 손쓰면 된다"는 것이 핵심 메시지입니다.
사실 -> 원인으로 볼 만한 지점 -> 지금 할 수 있는 일 순서로 씁니다.
학부모를 탓하는 표현은 쓰지 않습니다.

단, 그 학생의 trend 가 "up" 이면 이 지침을 적용하지 않고 격려형으로 씁니다.
전체가 내려갔어도 오른 학생에게 경고문을 보내면 안 됩니다.
```

## User

```
[원장 요청 사항]
{context_comment}

{analysis_json}
```

- `{context_comment}` — H2A 가 통과시킨 원장 코멘트 원문 (팀 합의 N-3)
- `{analysis_json}` — 분석 노드 출력 `payload` 전체

> **`edu.roster@1` 원본은 넣지 않는다.** 과목별 원점수 80개가 다시 들어가면
> 토큰만 늘고 모델이 개별 점수를 문장에 나열하기 시작한다.
> 집계 결과만으로 충분하다 (데이터 최소 전달, AI-05-5).

## few-shot — User 뒤에 붙인다

세 통이면 충분하다. 더 넣으면 모델이 예시 문장을 그대로 베낀다.

<!-- prompt:fewshot -->
```
아래는 문체 참고용 예시입니다. 내용은 베끼지 말고 형식만 참고하세요.

{
  "letters": [
    {
      "student_name": "김서린",
      "tone": "encourage",
      "body": "김서린 학생은 이번 달 평균이 6.5점 올라 78.3점을 기록했습니다. 특히 꾸준히 붙잡고 있던 영어에서 변화가 뚜렷했습니다. 다만 과학이 아직 다른 과목보다 낮은 편이라, 다음 달에는 과학 복습에 조금 더 시간을 배분해 보면 좋겠습니다."
    },
    {
      "student_name": "박새힘",
      "tone": "warn",
      "body": "박새힘 학생은 이번 달 평균이 7.2점 내려 66.8점이 되었습니다. 수학이 가장 많이 흔들렸는데, 단원이 어려워지는 시기라 이맘때 자주 나타나는 흐름입니다. 지금 기초 문제를 다시 한 번 훑으면 충분히 회복할 수 있는 폭이니, 다음 주 보충 수업을 함께 검토해 주시면 좋겠습니다."
    },
    {
      "student_name": "정라온",
      "tone": "warn",
      "body": "정라온 학생은 이번 달 평균 71.0점으로 지난달과 큰 차이는 없었습니다. 다만 국어가 다른 과목에 비해 낮게 유지되고 있어 눈여겨보고 있습니다. 독해 문제를 하루 한 지문씩만 꾸준히 풀어보도록 지도하겠습니다."
```

세 예시가 각각 **상승 · 하락 · 보합**을 담당한다. 톤이 셋 다 다르면서도 구성
(사실 → 근거 → 제안)은 같다는 것을 보여주기 위한 배치다.

## 준수율 목표

로드맵 AI-06-7 기준 **W3 월 1차 90% · W4 월 최종 95%.**
각 10회 실행해 `check_compliance.py` 로 잰다. 보는 것은 네 가지다.

| 검사 | 왜 보는가 |
| --- | --- |
| `letters` 개수 == 학생 수 | 가장 흔한 실패. 20명 중 몇 명이 조용히 빠진다 |
| 이름이 입력 명단과 정확히 일치 | 없는 학생을 만들거나 이름을 바꾸는 경우 |
| `tone` 이 `trend` 와 맞는가 | 오른 학생에게 경고문이 가면 시연이 무너진다 |
| 금칙어 미포함 | 학부모에게 나가는 글이다 |

90% 미만이면 프롬프트를 고친다. 로드맵 W3 월요일 항목 그대로다.

## 보안

이 문서의 프롬프트 원문은 **응답 · 로그 · 예외 메시지 어디에도 나가지 않는다** (SEC-001).
Runtime 은 `prompt_ref` 로 참조만 받고 원문은 내부에서 조회한다 (팀 합의 N-7).
few-shot 예시의 이름도 전부 생성값이며 실존 학생과 무관하다.
