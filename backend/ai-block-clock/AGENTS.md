# AGENTS.md

코드 규칙은 [`docs/RULE.md`](docs/RULE.md), 서식은 [`CLAUDE.md`](CLAUDE.md) 에 있다.
이 문서는 **일하는 방식**만 적는다.

## 커밋과 MR

**제목 한 줄만 쓴다. 본문을 쓰지 않는다.**

```
[S15P21A403-79] fix: 노드 삭제와 배치가 같은 행을 잠근다
```

왜 그렇게 했는지는 MR 본문에 적는다. 커밋마다 경위를 늘어놓으면 같은 이야기가 커밋과
MR 두 곳에 갈라져 남고, 나중에 어느 쪽이 최신인지 알 수 없게 된다.

**도구 서명을 남기지 않는다.** 커밋 메시지의 `Co-Authored-By: Claude ...` 트레일러도,
MR 본문의 `🤖 Generated with Claude Code` 줄도 넣지 않는다. 기본 설정이 자동으로 붙이려 하더라도
붙이지 않는다. 누가 썼는지는 커밋 author 와 MR author 가 이미 말한다.

## 지시한 범위만 한다

- **브랜치를 임의로 만들지 않는다.** 지금 체크아웃된 브랜치에서 작업한다
- **커밋 · 푸시 · MR 생성은 요청받았을 때만 한다.** 앞서 한 번 승인받았다고 다음에도
  되는 것이 아니다
- **묻지 않은 문서를 쓰지 않는다.** 정리해 달라고 하면 먼저 대화로 보여준다
- 고치라고 한 것만 고친다. 옆에 보이는 것을 같이 손대지 않는다

## 단정하기 전에 확인한다

그 코드가 실제로 불리는지부터 본다. 빈으로 등록되지 않은 정책, 주입받는 데 없는 Reader,
항상 같은 값을 돌려주는 스텁을 두고 설계를 논하지 않는다.

틀렸으면 취소하고 한 번에 고친다. 같은 물음에 서로 다른 답을 세 번 내놓지 않는다.
